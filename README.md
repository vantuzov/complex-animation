## Описание проекта

Графическая анимация на Python с использованием Tkinter. С помощью полярных координат реализуется плавное превращение круга в треугольник, как на приведённой анимации.
Фигура отображается на холсте Tkinter.

## Технологии

- Python 3
- Tkinter

Tkinter входит в стандартную библиотеку Python, поэтому устанавливать дополнительные пакеты для проекта не требуется.

## Установка и запуск

### 1.Клонировать репозиторий:

git clone https://github.com/vantuzov/complex-animation.git
cd complex-animation

### 2.Создать виртуальное окружение:

python -m venv venv

### 3.Запустить программу:

python main.py

## Пример использования
